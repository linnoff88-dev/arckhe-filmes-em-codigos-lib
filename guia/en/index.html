Filmmaking with code lets you change the camera and keep the scene.

Imagine asking for just a slower camera and getting a different sea, different light, a different temple. When AI writes the scene as a program, you can adjust the speed and return to the same place. Watch the examples and see how they were made, even if you’ve never written code.

In brief

You want to change one detail in a film and keep what already works. This library shows how AI can write the instructions that draw each image. If you’re curious and have never programmed, start with a demo, then open the project to see how the creator made that scene. All you need to explore is a browser.

How does a program become a film?

The scene gets its rules

Think of a boat crossing the screen. The program describes the boat’s shape, the color of the water, and how far it travels each second. Canvas is the browser’s drawing surface. WebGL uses the graphics processor to draw on it, and three.js makes it easier to create three-dimensional scenes. Another option is to control the Blender animation studio with a Python script.

The clock picks the frame

When you ask for the moment at two seconds, the program places the boat where it belongs at that point in time. Even the waves can repeat if the random generator that shapes them starts with the same number, called the seed. With the same rules, seed, and runtime conditions, you can recreate just that frame or resume an interrupted sequence.

The images get sound

A browser can run without opening a window and save an image for each moment. In Blender, the program itself calculates the images. A tool called FFmpeg arranges the frames at the chosen speed and combines them with narration, music, and sound effects.

What look do you want for the scene?

Style

In watercolor, a blue mark can suggest the sea. In anime, a few bands of shadow can give a face depth. Simple drawings can run on a computer’s regular processor (CPU) at low cost. More complex styles also use graphics acceleration.

High realism

To recognize wet marble, the eye looks for the reflection of the sky on the stone. Path tracing calculates how light bounces between surfaces. Rules can also create mountains, water, and clouds. Calculating everything at high resolution usually requires a graphics processor (GPU) and can take hours.

How do you know what needs improvement?

Choose a reference and generate a test frame. In the Cook Loop method, evaluators who don’t know the creator’s decisions compare the two images. If the temple looks like a miniature, for example, they might point out the scale of the columns. The creator adjusts the scene and repeats the comparison before rendering the entire film.

Look at the edge of the roof as the camera passes. If it looks like a staircase, the program can combine several slightly offset samples. This average smooths the jagged edges (anti-aliasing). Samples from nearby moments also leave a soft trail in the motion, like a camera.
